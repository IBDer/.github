# Support / 获取帮助

IBDer builds open-source tools and publishes open research. It is not a medical service, patient forum, or emergency channel.

IBDer 建设开源工具并发布开放调研，但不提供医疗服务、患者论坛或紧急求助渠道。

## Project support / 项目支持

For reproducible software bugs, documentation problems, research questions, or project proposals, use the relevant repository's issue form. Search existing issues first and provide only the minimum information required.

对于可复现的软件问题、文档问题、研究问题或项目提案，请使用相关仓库的 Issue 表单。提交前请先搜索已有 Issue，并仅提供解决问题所需的最少信息。

## Medical help / 医疗帮助

Do not use GitHub issues to request diagnosis, treatment recommendations, disease-score interpretation, or emergency help. Contact a qualified healthcare professional for medical questions. In an emergency, contact local emergency services immediately.

请勿通过 GitHub Issue 寻求诊断、治疗建议、疾病评分解释或紧急帮助。医疗问题请咨询专业医疗人员；紧急情况下请立即联系当地急救服务。

Never post medical records, identifying health information, credentials, or private communications.

请勿公开医疗记录、可识别的健康信息、凭证或私人通信。
