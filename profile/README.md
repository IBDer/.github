# IBDer

**由 IBD 患者参与共建研究与工具的开放社区。**

从可信的研究与政策信息，到正在孵化的 IBDer App，再到未来的开放工具。

</div>

## 社区内容

| 方向 | 内容 | 状态 |
| --- | --- | --- |
| [研究与信息](https://github.com/IBDer/research) | 整理可追溯的研究动态、证据与地区政策 | 建设中 |
| [IBDer App](https://github.com/IBDer/IBDer) | 记录饮食、用药、症状与诊疗事件的患者自我管理工具 | 孵化中 |
| 开放工具 | 围绕患者真实问题规划更多可复用工具 | 规划中 |

## 我们的边界

IBDer 是独立的患者共建型开源社区，不隶属于任何医院、药企或商业机构。我们不提供诊断、个体化治疗建议、远程问诊或紧急服务，也不会公开可识别的患者信息。

社区内容不能替代专业医疗建议。紧急情况下，请立即联系当地急救服务。

## 如何参与

你可以阅读和补充资料、提出真实需求、测试工具或参与设计与开发。请从 [Discussions](https://github.com/orgs/IBDer/discussions) 开始；提交前请阅读[参与指南](https://github.com/IBDer/.github/blob/main/CONTRIBUTING.md)与[隐私规则](https://github.com/IBDer/.github/blob/main/PRIVACY.md)。

IBDer 由患者问题驱动，由人类负责判断，AI 参与调研、设计、开发与维护。重要 AI 参与会被说明，最终内容由人类维护者负责。
